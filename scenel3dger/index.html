01 · model

Architecture overview

Each RGB frame is encoded along two frozen visual paths. All 192 aligned patch pairs update a bank of free associative registers; no frame tokens or explicit 3D map survive after the update.

Constant persistent stateStream length changes compute, not stored state: only the newest 512 registers persist.
No explicit 3D memory inputTTT3R contributes post-decoder visual tokens; XYZ boxes supervise only a transient reader.
Free associative slotsA slot is not assigned a fixed place or time. Observation coordinates affect Q/K RoPE only.
One deployed answer pathEvery benchmark answer is generated by Qwen from all projected memory cells plus the text query.

Can the fixed memory reconstruct metric 3D state?

Pose and object geometry are not inputs to the memory. They are target-only sidecars: lightweight readers must recover them from the RGB-derived memory, and their gradients are intended to teach the writer what metric information to preserve.

05 · experiment contract

What is fixed

The current run is deliberately frozen so that restarts do not silently change the method while diagnosing long-run behavior.

Data

  • Train: 976,220 QA rows across 4,897 scenes.
  • Validation: 50,258 rows across 257 held-out scenes.
  • Visual cache: 5,154 scenes with aligned Qwen and TTT3R tokens.
  • Objects: 308,406 targets across 5,221 semantic labels.

Optimization

  • Compute: 8 × H200, per-rank batch 2, BPTT 16 frames.
  • LR: memory 2e−4; Qwen LoRA 1e−5.
  • Schedule: 1,000-step warm-up, 183,045 target steps.
  • Validation/checkpoint: every 1,000 / 5,000 steps.

Audit boundary

  • Checkpoint: step 65,000, 3.28 GB, tensor-finite scan passed.
  • Eval: exact released 10k IDs and temporal policy.
  • Answers: memory → projector → one Qwen generation path.
  • Not used in answers: object and pose auxiliary heads.
appendix · where object supervision came from

Persistent-object target pilot

Before training the object reader, we verified on one continuous ScanNet scene that fragmented SAM3 tracks can resolve to stable annotated 3D identities across long absences.

Native 30 FPS RGB · 2 Hz perception/registry update · no temporal cutsScanNet scene0003_02
34.0 s maximum absenceThe microwave reappears under its original persistent object identity.
Fragmented tracks mergeMultiple SAM-local trash-can identities map to one ScanNet 3D instance.
Late objects are admittedThe door and backpack first enter the registry after 32.5 seconds.

The memory is constant-size and the full pipeline runs—but the current optimization is not yet learning a competitive memory.

The next defensible milestone is not another architectural claim. It is to repair the non-finite writer gradient, rerun the frozen comparison, and show that held-out QA and correct-scene margins improve before the next official 10k evaluation.
