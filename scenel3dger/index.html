What the pilot actually does

The experiment separates 2D perception from persistent 3D identity. This is a target generation pipeline for memory supervision, not a claim that SAM3 alone predicts metric 3D.

RGB stream

Use the full 30 FPS ScanNet sequence. A frame is sampled every 0.5 seconds for tracking.

SAM3 masks

Five fixed text prompts produce per-frame masks and model-local track IDs.

3D association

Mask overlap plus class agreement resolves each valid observation to one stable ScanNet instance.

Persistent registry

Track fragments merge by 3D ID; center, extent, last-seen time, and visibility survive absence.

!
SAM3D was not used here. ScanNet already supplies persistent instance IDs and metric 3D annotations, so adding a learned image-to-3D reconstruction stage would only inject avoidable error. In an in-the-wild video without 3D labels, that stage becomes necessary.

Training from step 50 to 200 also produces little qualitative improvement. This small panel therefore supports a failure diagnosis—weak scene-specific readout—not a performance conclusion.

Protocol and limits

This is a feasibility demonstration for designing object-level memory supervision. It is not an object-tracking benchmark.

Fixed setup

  • Scene: ScanNet v2 scene0003_02, one continuous 44.5-second scan.
  • Prompts: water cooler, trash can, microwave, door, backpack.
  • Tracking: original SAM3 checkpoint, 2 Hz sampled RGB, no manual mask clicks.
  • Association: exact class agreement plus 2D instance-mask overlap; mean accepted IoU 0.690.

What is and is not learned

  • Predicted: text-conditioned SAM3 masks and SAM-local track identities.
  • Supervised: persistent object identity, center, extent, and reappearance from ScanNet annotations.
  • Not tested: open-vocabulary recall, SAM3D reconstruction error, or memory-capacity scaling.
  • Next experiment: turn each registry entry into a decoder query target for SceneL3DGER memory training.

The supervision signal is viable: one 3D object target can span fragmented 2D tracks and long visual absence.

The next step is not another tracking heuristic. It is to train memory queries to recover these object identities, metric locations, and semantic features from the fixed-capacity SceneL3DGER state.
