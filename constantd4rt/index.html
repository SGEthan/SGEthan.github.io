为什么现在更快

优化没有改变 checkpoint 或 recurrent state 顺序；它重新组织了彼此独立的 observation encoding，并移除了逐帧同步。

01 · STAGE
Pinned frame window
最多 8 个 causal pairs，non-blocking H2D，不把完整视频留在 GPU。
→
02 · ENCODE
Batched frozen ViT-g
一次编码 8 个独立的 `(I[t−1], I[t])`，提高 B200 利用率。
→
03 · UPDATE
Sequential state updates
`S[t−1] → S[t]` 仍按时间顺序执行，每帧 query 不使用未来 observation。

默认 · Throughput mode

--observation-batch-size 8
165.84 FPS；固定显存；最多 8 帧等待延迟。

Strict streaming mode

--observation-batch-size 1
每帧立即编码和输出；适合最低延迟，而非最高吞吐。
